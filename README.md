# Optimized PDF

The color-restored document and its page-by-page correction report are available under [Releases](https://github.com/TheRealSonicFan/optimized-pdf/releases).

- **1-print-optimized.pdf** — 16 pages, individually corrected for color and tone, preserving native 300 dpi resolution, letter-size page geometry, and the original searchable text layer. Lossless compression; approximately 146 MiB.
- **1-color-correction-report.pdf** — 18 pages of analysis, before/after comparisons, and printing guidance.
- **upload-checksums.sha256** — SHA-256 checksums for both PDFs.

The PDFs are release attachments because the lossless master exceeds GitHub's 100 MiB repository-file limit. The source scans' remaining wear and halftone texture are retained; printer-specific color accuracy requires a physical proof.
